About Cinelist

Cinelist is a movie discovery and management platform developed using Django and the TMDB API. It allows users to browse trending and upcoming movies, explore cast and reviews, and maintain personalized Watchlists and Wishlists.

Features

  • Search for movies by title
  • Detailed movie pages with posters, genres, and ratings
  • Top cast and user reviews display
  • Watchlist and Wishlist management
  • Modern responsive design

Technologies Used

  • Python & Django
  • Django Templates, HTML5 & CSS3
  • Font Awesome for icons
  • TMDB API

Credits

This project uses the TMDB API but is not endorsed or certified by TMDB.
